# Asset provenance

The notification icon artwork is generated from source in this repository. The four bundled
audio files are original sounds supplied by the project author; their sound
design source is private and is not included in the public repository.

- `codex-notifier.png`: original bell-and-check artwork, rendered at 512 x 512 from editable `assets/notification-bell.svg` by `scripts/generate-assets.py`. A burnt-orange outline bell with a curved rim contains a completion check on light ivory. The sidebar header uses the same full-color SVG.
- `icon.svg`: the same original bell and completion check, rendered in `currentColor` for VS Code themes and sidebar controls.
- `media/codex-blue.svg`, `media/codex-blue-dim.svg`, `media/codex-green.svg`, and `media/codex-gray.svg`: color variants of an original compact bell-and-check silhouette defined in `scripts/generate-assets.py`. The filenames identify the extension's Codex activity states; their geometry contains no OpenAI, Microsoft or Ubuntu logos.
- `sounds/synth-1.wav` through `sounds/synth-4.wav`: four original stereo PCM startup cues supplied by the project author. The distributed cues retain their original soft stereo texture, with notes retuned into brighter major chords and durations shortened to 1.1 seconds. Their production scripts are intentionally private; the committed WAV files are the distribution artifacts.

The original bell-and-check artwork, bundled sounds and public icon generator are distributed under the repository's MIT license subject to Commons Clause v1.0. Current distributed artwork contains no copied vendor logo geometry. Earlier visual experiments are local private material and are not public distribution sources.
Icon generation requires the development-only Pillow dependency in `requirements-assets.txt`, GJS and GdkPixbuf's SVG loader. The extension itself has no Pillow dependency.

With the `aiml` environment already active:

```bash
python -m pip install -r requirements-assets.txt
npm run assets:icons
```

Edit `assets/notification-bell.svg` to change the icon's palette or geometry. `npm run assets:icons` regenerates the production PNG, monochrome Activity Bar SVG, inline sidebar marks and top-bar state icons. Keep the bundled WAV files when regenerating icons.

`docs/screenshots/` contains a screenshot of the actual GTK notification and two GTK previews of the top-bar artwork, captured with synthetic content by `scripts/capture-readme.js`. No real conversations or desktop screenshots are included. To regenerate them in an X11/XWayland desktop session, run `GDK_BACKEND=x11 gjs scripts/capture-readme.js`. The top-bar layout is generated by `lib/topbarArtwork.js`, which the live indicator also uses.

Yaru sounds are optional references to files already installed on the user's
system. They are not bundled, copied or relicensed by this extension. Missing
Yaru presets are hidden. Imported user audio stays in the user's existing local
sound directory and is never included in the VSIX.

This is an independent extension, not an official OpenAI or Microsoft product.
