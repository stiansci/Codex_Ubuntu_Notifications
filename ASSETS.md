# Asset provenance

The icon artwork is generated from source in this repository. The four bundled
audio files are original sounds supplied by the project author; their sound
design source is private and is not included in the public repository.

- `codex-notifier.png`: Signal Bell, the user-selected proposal 01, rendered at 512 x 512 by `scripts/generate-assets.py` using the original geometry in `scripts/generate-icon-variants.py` and palette in `assets/signal-bell.json`.
- `icon.svg`: a matching original monochrome bell-and-check outline, generated by `scripts/generate-assets.py`. Transparent badge separation and `currentColor` allow VS Code to tint it for the active theme.
- `sounds/synth-1.wav` through `sounds/synth-4.wav`: four original stereo PCM startup cues supplied by the project author. They use a soft ambient mood. Their production scripts are intentionally private; the committed WAV files are the distribution artifacts.

The generated icons, bundled sounds and public icon generators are distributed under the repository's MIT license subject to Commons Clause v1.0.
Icon generation requires the development-only Pillow dependency in `requirements-assets.txt`. The extension itself has no Pillow dependency.

With the `aiml` environment already active:

```bash
python -m pip install -r requirements-assets.txt
npm run assets:icons
```

Edit `assets/signal-bell.json` for colors, scale, offset and corner radius. Edit the shared Python `build()` function for the color icon's shapes and `generate_icons()` for the simplified Activity Bar outline. No image model or external artwork is needed. `npm run assets:icons` regenerates only the icons. Keep the bundled WAV files when regenerating icons.

Yaru sounds are optional references to files already installed on the user's
system. They are not bundled, copied or relicensed by this extension. Missing
Yaru presets are hidden. Imported user audio stays in the user's existing local
sound directory and is never included in the VSIX.

This is an independent extension, not an official OpenAI or Microsoft product.
